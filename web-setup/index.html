Connect with your phone

  1. On the pet, open Settings → Phone setup.
  2. Join the Wi-Fi network shown on its screen using the displayed password. Stay connected if your phone reports no internet.
  3. Open the local setup page, save your settings and choose Done when the pet confirms the connection.
Open pet setup

The setup page lives on the pet at 192.168.4.1.

Settings over USB

Use a data cable and desktop Chrome or Edge. Open Settings → Phone setup on the pet to see the pairing password. USB settings require the setup-preview firmware or later compatible firmware.

Update firmware

Install 0.3.22-setup-preview on an existing 0.3.21-amplifier pet. This preview adds USB settings. Its browser update path has host-test coverage and awaits a physical installation test.

Connecting for an update restarts the pet. Finish any voice session first. Keep a private copy of the backup; it contains device credentials.
